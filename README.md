# 世局 · 验收版本

SillyTavern 1.16 / 1.17 第三方扩展，提供世界账、增量演进、只读世界书 EJS 与独立模型请求。

版本：0.1.0-acceptance.20261029；来源提交：6f0aa918b03e888c558a894fc42989b3e2ed384d。

已安装本仓库时，在酒馆扩展管理中点击世局的更新按钮，完成后刷新页面；不必卸载重装。

本次更新：
- 自定义渠道支持获取模型列表、测试连接和可选流式传输；配置草稿变化后旧测试结果失效。
- 请求历史记录所有世局模型请求，提供用量、原始消息、错误、复制与导出；修复占位密钥影响历史状态的问题。
- 历史按账号保存到独立文件 user/files/shiju-request-history-v1.json，最多 30 条，压缩编码后最多 2 MiB；超限淘汰旧记录，单条过大时仅持久保存摘要。文件可能被清理工具判为未引用，请勿清理。设备轮流使用时刷新，不保证同时写入。
- 设置按演进、模型、资料、外观、记录分类；后台更新时保留历史阅读状态。
- 事件、今日变更、地区、势力与组织可展开详情，查看与修正分开；空正文明确提示，隐秘继续遮挡。

验证：1525 项现有检查、API 专项、普通预览及夹具浏览器回归通过；桌面和 375px 窄屏详情交互验证通过。本轮使用虚构数据和固定回复，无真实模型调用。前序隔离酒馆 1.16 / 1.17 组合验收记录见源码包 COMPATIBILITY-VALIDATION.md。

默认关闭流式；主动测试连接可能收费。详情展示已有记录，不补写缺失正文，也不会为了补足事件数量自动请求模型。

本仓库为单文件安装构建，不含聊天、密钥、个人配置或原仓库历史。完整对应源码、测试、依赖锁文件、构建脚本与第三方许可证在 source.zip；源码包相对来源提交仅调整发布版本号，并补充发布构建脚本与根目录许可证。

重建：解压 source.zip，执行 npm ci、npm run build，再执行 node scripts/build-distribution.mjs dist。运行无需安装 npm 依赖。
