# 世局

SillyTavern 1.16 / 1.17 第三方扩展，提供世界账、世界演进、只读世界书 EJS 与独立模型请求。

版本：**0.1.2**；构建标识：`0.1.2+3e4d5858218f`；来源提交：`12c96a7bf174f4710eaefe4836916ff7f31f6ef3`。

## 更新

在酒馆扩展管理中点击世局的更新按钮，然后刷新页面使 0.1.2 生效，无需卸载重装。运行 0.1.1 或更新版本时，支持更新回调的酒馆会提供“刷新生效／稍后”；没有提示时手动刷新即可。旧版酒馆在打开世局面板时检查本地安装版本。

## 本次修复

补齐后台任务的输出格式，修复提示词没有明确说明“今日变更”字段的问题：

- `todayChanges` 每项明确输出非空 `title`、`body` 和 `kind`；即使有 `linkedEventId` 也不能省略标题或正文。
- 区分 `facts[].text` 与事件／今日变更的 `title`、`body`，禁止用 `text` 等字段替代。
- 补齐实体、事件、关联、阶段和生命周期字段说明，提供中性 JSON 格式示例。
- 初始化仍要求今日变更为空，分类补全仍只输出目标分类。演进、重跑、重对齐和资料管理共用明确的字段说明。

本轮只调整任务提示词，不自动映射错误字段、不放宽校验、不增加失败重试。错误返回仍不会写入世界账。

验证：新增 56 项格式回归，覆盖九个实际任务出口、示例解析与保存、错误格式拒绝和失败不提交；全套 1743 项代码回归、API／请求历史检查和构建通过。使用中性固定回复，真实模型调用 0 次。没有发布用户聊天或请求记录。

0.1.1 已提供魔法棒常驻入口、悬浮球开关、更新提醒，以及可点击的日期／历史修改诊断。相关桌面、375px 和隔离酒馆 1.16 / 1.17 验收记录见源码包 COMPATIBILITY-VALIDATION.md。

此前已提供完整资料输入、主动演进、地区／势力／组织管理、重新初始化与备份恢复、自定义 API、流式请求及请求历史。完整发送不代表渠道一定接受；主动测试连接、立即演进和资料重新生成会请求模型，可能收费。

请求历史按账号保存在独立文件 user/files/shiju-request-history-v1.json，最多 30 条、压缩编码后最多 2 MiB；请勿将其作为未引用文件清理。设备轮流使用时刷新，不保证多设备同时写入。

## 源码与重建

本仓库为单文件安装构建，不含聊天、密钥、个人配置或原仓库历史。source.zip 包含对应提交的完整源码、测试、依赖锁文件与第三方许可证，另补充发布构建脚本和根目录许可证；源码与安装包的版本标识一致。

重建：解压 source.zip，执行 `npm ci`、`npm run build`，再执行 `node scripts/build-distribution.mjs dist`。发布时一并使用生成后的清单与代码，不单独改清单版本。运行无需安装 npm 依赖。
