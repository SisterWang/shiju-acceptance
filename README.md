# 世局

SillyTavern 1.16 / 1.17 第三方扩展，提供世界账、世界演进、只读世界书 EJS 与独立模型请求。

版本：**0.1.1**；构建标识：`0.1.1+2861ddce0190`；来源提交：`eaef29eac7c48c49fc75b6cc24821c176209c4dd`。

## 更新

已安装本仓库时，在酒馆扩展管理中点击世局的更新按钮，无需卸载重装。**首次从旧版升级到 0.1.1 后，请手动刷新一次酒馆页面。** 新版运行后，支持更新回调的酒馆会提供“刷新生效／稍后”；旧版酒馆在打开世局面板时检查本地安装版本。

## 本次修复

- 魔法棒菜单常驻“世局”入口，复用现有面板；设置 → 外观可以关闭悬浮球，关闭后保留原位置。
- 更新后提供刷新提示；选择稍后后，设置仍保留入口。刷新前检查运行中的请求、保存、草稿与未采用预览，需明确确认，不自动刷新。
- 修复故事日起点不同导致的日期误判，手动校正同步日期基准。
- 历史正文修改与日期冲突分别提示；点击顶部提示直达时间校正，显示冲突双方日期、来源、楼层及处理方式。
- “复兴纪元488年1月4日 22:15”可读取，同日时分变化不额外跨日。真实来源矛盾仍阻止演进，“保持现状”不会将其当作已修复。

验证：1687 项代码回归、API／请求历史检查与构建通过；桌面、375px 窄屏及隔离酒馆 1.16 / 1.17 的入口、日期、刷新保护验收通过。本轮专项模型调用 0 次。验收记录与完整说明在 source.zip 的 COMPATIBILITY-VALIDATION.md、README.md、CORE.md 和 UI-CONTRACT.md。

此前已提供完整资料输入、主动演进、地区／势力／组织管理、重新初始化与备份恢复、自定义 API、流式请求及请求历史。完整发送不代表渠道一定接受；主动测试连接、立即演进和资料重新生成会请求模型，可能收费。

请求历史按账号保存在独立文件 user/files/shiju-request-history-v1.json，最多 30 条、压缩编码后最多 2 MiB；请勿将其作为未引用文件清理。设备轮流使用时刷新，不保证多设备同时写入。

## 源码与重建

本仓库为单文件安装构建，不含聊天、密钥、个人配置或原仓库历史。source.zip 包含对应提交的完整源码、测试、依赖锁文件与第三方许可证，另补充发布构建脚本和根目录许可证；源码与安装包的版本标识一致。

重建：解压 source.zip，执行 `npm ci`、`npm run build`，再执行 `node scripts/build-distribution.mjs dist`。发布时一并使用生成后的清单与代码，不单独改清单版本。运行无需安装 npm 依赖。
