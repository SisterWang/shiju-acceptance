# 世局 · 验收版本

SillyTavern 1.16 / 1.17 第三方扩展，提供世界账、世界演进、只读世界书 EJS 与独立模型请求。

版本：0.1.0-acceptance.20261030；来源提交：3eda1d4040c8dc0fde7377b8160b19eadc019f8a。

已安装本仓库时，在酒馆扩展管理中点击世局的更新按钮，完成后刷新页面；不必卸载重装。

本次更新：
- 移除固定输入字符数和楼层数裁剪；初始化、重新初始化和分类补全读取全部合格世界书正文。聊天背景使用完整有效记忆与未覆盖原文，手动排除仍有效。
- 常规演进新增绿灯补发现轮转。无新增剧情时也可主动演进，不自行推进日期；允许平静结果，不要求凑事件数量。
- 地区、势力、组织支持手动新增、修改及分类补全；模型结果先预览再采用，保留人工内容和稳定关联。
- 支持重新初始化、重建前备份导出和确认恢复。采用后重建剧情基线并清空旧演进日志和重跑点，保持启用／冻结状态与聊天偏好。
- 可选上下文上限绑定连接和模型，检查完整消息及输出预留，超限停止而不裁剪。完整发送不代表渠道一定接受。
- 修复重跑丢失人工资料、重建导致隐秘公开、隐藏记忆重复承接和模型切换误用旧上下文额度；失败和过期预览不覆盖世界账。

验证：1525 项既有检查、70 项世界管理检查和 44 项 review 回归，以及 API／历史检查和构建通过。桌面、375px 窄屏浏览器自检和隔离酒馆 1.16 / 1.17 管理验收通过。使用虚构数据与本地固定回复，真实模型调用 0 次。完整记录见源码包 COMPATIBILITY-VALIDATION.md。

默认关闭流式；主动测试连接、立即演进和资料重新生成会请求模型，可能收费。请求历史按账号保存在独立文件 user/files/shiju-request-history-v1.json，最多 30 条、压缩编码后最多 2 MiB；请勿将它当成未引用文件清理。设备轮流使用时刷新，不保证多设备同时写入。

本仓库为单文件安装构建，不含聊天、密钥、个人配置或原仓库历史。完整对应源码、测试、依赖锁文件、构建脚本与第三方许可证在 source.zip；源码包相对来源提交仅调整发布版本号，并补充发布构建脚本与根目录许可证。

重建：解压 source.zip，执行 npm ci、npm run build，再执行 node scripts/build-distribution.mjs dist。运行无需安装 npm 依赖。
